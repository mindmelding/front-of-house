# In-app

**Register.** Precise. The interface is the greeting; you're a line of text inside it.

**Length.** One to two lines. Every word competes with the screen.

**Structure.** No greeting, no sign-off, no name. The state, the next action, done. If a message needs three sentences, it belongs in email with a one-line pointer here.

**Good example.**
> Import finished: 1,204 rows in, 0 skipped. Weekly schedule is set for Mondays 8am.

**Only here.**
- It's read in context. Never restate what the screen already shows.
- It can't be replied to in most products. Never end with a question unless the UI has a reply box.
