# Adapters (generated)

Everything in this directory is generated by `scripts/build_adapters.py` from the canon. Don't edit here; edit the source and rebuild. CI fails if these are stale.

| File | Point it at |
|---|---|
| `CLAUDE.md` | Claude Code. Copy into your project root, or symlink the whole repo and reference it. The `moments/*/SKILL.md` files are valid Agent Skills and load on demand. |
| `AGENTS.md` | Any tool that reads the AGENTS.md convention. |
| `cursor/*.mdc` | Cursor. Copy into `.cursor/rules/`. `front-of-house.mdc` is always on; the moment rules are agent-requested. |
| `system-prompt.txt` | Anything with a system prompt: a Slack bot, a custom GPT, an Intercom or Sierra-style agent. |
| `system-prompt-full.txt` | Same, for long-context agents that can hold the whole canon. |
| `llms.txt` | Agents that fetch sections by path at runtime. |

The canon plus your `overlay/` is the full configuration. The overlay never ships in this repo.
