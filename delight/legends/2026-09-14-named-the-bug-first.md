# Named the bug before they found it

**Date.** 2026-09-14
**Trigger.** A failed import on an account whose file said they run imports every Tuesday for a Wednesday report.
**What we noticed.** Row 5 showed the failure at 6:12am. Row 8 said the desired outcome was "the Wednesday report goes out without me touching it." They had not written in yet.
**What we did.** Corrected the one bad row, re-ran the import, then: "Your Tuesday import failed on one row (a DD/MM date). I've fixed the row and re-run it; all 1,204 records are in, so Wednesday's report is safe. Sorry, one bad row shouldn't fail the file. That's logged as FOH-212 and I'll tell you when it ships."
**What happened.** Their reply: "I hadn't even opened my laptop yet." They forwarded it to their team.
**The move to reuse.** When the file tells you what an error will cost them, fix it and name it before they have to.
